- 元の情報: ざすこ（道草 雑草子、@zasuko_michiksa）のX投稿（2026-11-19）。自身と猫キャラ「ジェネコ」の図解アニメを Claude Code と一緒に全部コードで作った制作報告で、YouTube「AIみちくさチャンネル」の紹介も兼ねている。方法は gear machine@AI（@grmchn4ai）の投稿を参考にしたとのこと（元の投稿自体は未確認）。声は VOICEVOX:櫻歌ミコ。
- 要点: 作りは4層。①絵を目・口・髪などの部品に分けた、線なしのベクター人形。②体の動きは文章から骨の動きを作るAI「Kimodo」（NVIDIA）。③口パクは声の大きさで自動生成し、まばたき・息づかい・視線も自動。④カット割り、図解、字幕もコードで生成。動画生成AIに絵を描かせないので、キャラの見た目が崩れず、直しもコード側で効く。
- Kimodoについて（NVIDIAの公開情報で確認）: 文章＋拘束条件から人型のモーションを作る拡散モデルで、出力は BVH／NPZ。コードは Apache-2.0、SOMA／G1 のモデルは NVIDIA Open Model License で商用利用可（SMPL-X版のみ研究用ライセンス）。GPU生成には約17GBのVRAMが要り（文章の埋め込み側が大きいため）、検証例が多いのは RTX 3090／4090。文章の読み取りに Llama 3 8B Instruct を使うため、そのアクセス申請とトークンが別途要る。
- 面白いところ: 「喋る解説動画」を、生成動画ではなく部品とプログラムの組み合わせで作っているところ。本人の muse-stage（VOICEVOXの声＋VRMの姿でプレゼン共演）や、読む聞くサイトの動画宣伝と同系統の発想で、こちらは2Dのベクター人形＋自動口パクという軽い形。Kimodo の BVH 出力は、VRM側のモーション作りにも転用できる可能性がある。
- 作れそうなもの: 台本→VOICEVOX音声→口パクと身振りを自動で付けて図解アニメ化、という量産の型。記事や本の内容を「ミューズさんが喋る解説動画」に変える用途が近い。棒人間アニメ自動生成（登録済み）とは、絵の作り（生成動画かベクター人形か）の違いで書き分け。
