- 元の情報: DEXTUNE（@dextune）のX投稿（2026-11-22）。一次情報は GitHub baenv/beanfx のREADMEで確認。ライセンスはMIT。
- 使い方: Claude Code のプラグインマーケットプレイスから入れる（/plugin marketplace add baenv/beanfx）。前提は Rust（cargo）。初回実行で専用バイナリがプロジェクト内にビルドされ、エフェクト1件ごとに小さなRustプロジェクト（drafts/<名前>/）ができる。中身はエフェクト本体のコード、ゲームが読み込むスプライトシート（PNG）とJSON、ダブルクリックで開けるプレビューHTML。描画だけでなく、音やチェックも含むキットが土台になっている。
- ゲームへの組み込み: 付属の JavaScript ランタイム（Canvas向け）か、Phaser の Aseprite 読み込みでそのまま使える。剣と杖のキャスター（横向きと見下ろし）のスプライトが同梱されていて、キャラに重ねた形でエフェクトを作れる。ライブデモとギャラリーが公開されていて、実際のゲーム「Nine Heavens」での採用例もある。
- 面白いところ: 登録済みの pixelfx（コードで書くピクセルエフェクト集＋Claude Code Skill）の直系で、README にも「光の層は pixelfx から学び、Rustで再実装した（コード自体は含まない）」と明記されている。pixelfx が「部品集」だったのに対し、こちらは「指示→コード生成→シート書き出し→ゲーム組み込み」までを1つのプラグインにまとめた形。生成物がコードなので、数値を直して再実行する本人の好みの回し方に合う。
- 作れそうなもの: 自作ゲームの魔法・斬撃エフェクトの量産。登録済みの「打撃感を出す8つの要素」と組み合わせると、見た目（エフェクト）と手触り（ヒットストップ等）の両側が揃う。
